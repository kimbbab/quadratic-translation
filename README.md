# 이차함수 그래프 활동

첫 화면에서 활동을 선택할 수 있습니다.

- `01-slider/index.html`: 슬라이더로 그래프 이동
- `02-step/index.html`: 방향 버튼을 누를 때마다 한 칸씩 이동
- `03-width-slider/index.html`: 그래프 아래 계수 슬라이더로 폭 조절
- `03-width-slider/question-2.html`: 폭 조절 문항 (2)
- `04-reflection-slider/index.html`: 그래프 아래 계수 슬라이더로 대칭인 그래프 그리기
- `04-reflection-slider/question-2.html`: 대칭 문항 (2)

평행이동 활동에서는 그래프를 옮기고 축의 방정식과 꼭짓점의 좌표를 입력합니다. 그래프의 폭과 대칭 활동은 (1), (2)가 각각 별도 페이지이며 이전 문항 / 다음 문항으로 이동합니다. 각 페이지의 슬라이더로 그래프를 조절하고 해당 문항만 채점합니다. 모든 활동은 채점, 풀이 보기, 다시하기를 지원합니다.

폭·대칭 슬라이더에는 계수 숫자를 표시하지 않습니다. 손잡이를 놓으면 정해진 계수 중 가까운 위치에 멈추며, 양옆 버튼과 키보드 방향키로도 정지 위치 사이를 이동할 수 있습니다.

폭 활동(03)의 기본값 계수 1은 슬라이더 정중앙입니다. 일곱 정지 위치를 같은 간격으로 배치하며, 다시 하기를 누르면 중앙으로 돌아갑니다.

정적 HTML, CSS, JavaScript로 구성되어 있습니다. `common-assets`는 공통 글꼴과 스타일, 이미지입니다. 각 페이지와 공통 자산의 상대 위치를 유지해야 합니다.

GitHub Pages는 `main` 브랜치의 루트 폴더를 게시합니다. 학습 결과의 서버 저장 및 LMS 연동은 포함하지 않습니다.
