# 이차함수 그래프 활동

첫 화면에서 활동을 선택할 수 있습니다.

- `01-slider/index.html`: 슬라이더로 그래프 이동
- `02-step/index.html`: 방향 버튼을 누를 때마다 한 칸씩 이동
- `03-width-slider/index.html`: 그래프 아래 계수 슬라이더로 폭 조절

각 활동에서 그래프를 옮기고 축의 방정식과 꼭짓점의 좌표를 입력한 뒤 채점할 수 있습니다. 풀이 보기와 다시하기를 지원합니다.

정적 HTML, CSS, JavaScript로 구성되어 있습니다. `common-assets`는 공통 글꼴과 스타일, 이미지입니다. 각 페이지와 공통 자산의 상대 위치를 유지해야 합니다.

GitHub Pages는 `main` 브랜치의 루트 폴더를 게시합니다. 학습 결과의 서버 저장 및 LMS 연동은 포함하지 않습니다.
